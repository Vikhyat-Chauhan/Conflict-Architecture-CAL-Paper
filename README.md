# Conflict Architecture — IEEE CAL Paper

Paper and supporting material for **"Brain-Inspired Drone Navigation Using the Conflict Architecture,"** drawn from my M.S. thesis at Virginia Tech and prepared for submission to **IEEE Computer Architecture Letters (CAL)**.

The Conflict Architecture (CA) is a deadline-aware adaptive planning framework for autonomous UAV navigation. Against conventional planners it achieves a **34.6% reduction in compute energy with zero deadline violations**, statistically significant (p < 0.0001) across 1,000 reproducible simulation runs in three real-world-derived environments.
